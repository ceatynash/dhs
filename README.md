# Daramombe High School Portal

Official Daramombe High School Portal repository. This application provides school portal access for parents/guardians, teachers, school administration, DOSA, and authorized developers.

## Run locally

1. Install dependencies with `npm install`.
2. Configure the required environment variables on the server (`GMAIL_USER`, `GMAIL_APP_PASSWORD`, and `DEVELOPER_EMAIL`). Set a strong `SESSION_SECRET` in production.
3. Start the application with `npm start`.

Do not commit credentials, OTPs, or real student records to the repository.
